# Yi in Colosseum

A Hollow Knight mod that brings **Yi from Nine Sols** into Colosseum of Fools!

Play as Yi with most of the transferred  combat mechanics, including parrying, talismans, Chi charges, Azure Bow and more.

This is my first mod project, and it's still in BETA, so expect some bugs!

## Key Binds

| Key | Action |
Arrows to move Yi
X - attack and hold X for charged attack
 F - Parry / Air Parry 
R - Charged Super Parry
 G - Talisman Dash / Detonation 
 H  - Medicine Pipe (Heal) 
 J  Azure Bow / K to change an arrow
L - press before exiting colloseum

## Important — Please Read!

⚠️ **Stay inside the Colosseum!**

The mod was designed specifically for  Colosseum of Fools.

**If you leave the Colosseum, you may not be able to enter it again!** Make sure you're ready before leaving.

Also, some original Hollow Knight mechanics are still present, including Crystal Heart and other abilities. It will be adjusted in further patches

## Known Issues

- Some animations and sounds may behave strangely.
- The mod isn't fully compatible with exploration outside the Colosseum.
- Occasional visual and combat bugs may occur.

## Installation

1. Install the Hollow Knight Modding API.
2. Place the mod's `.dll` file in the appropriate Mods folder.
3. Install the required assets according to the release instructions.
4. Launch Hollow Knight and enter the Colosseum of Fools.
